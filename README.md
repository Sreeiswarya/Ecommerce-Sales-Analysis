# 🛒 E-Commerce Sales Analysis

## 📌 Project Overview

This project is an end-to-end **E-Commerce Sales Analysis** project developed to analyze sales performance, profitability, customer behavior, product performance, payment preferences, geographical performance, and discount patterns.

The project uses **MySQL for data analysis** and **Power BI for interactive visualization and dashboard development**.

The objective is to transform raw e-commerce sales data into meaningful business insights and actionable recommendations.

---

## 🎯 Business Problem

The business wants to understand:

- Which states and cities generate the highest sales?
- Which product categories and products perform best?
- How are sales and profit changing over time?
- Which customers generate the highest revenue?
- How frequently do customers place orders?
- Which payment methods are most commonly used?
- How do discounts relate to sales and profitability?
- What business actions can improve sales and profitability?

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall sales and profit performance
- Identify high-performing states and cities
- Analyze monthly sales, profit, and order trends
- Identify high-performing and low-performing products
- Analyze product category profitability
- Understand customer order frequency and revenue contribution
- Analyze payment method usage
- Evaluate discount patterns and their relationship with profitability
- Create an interactive Power BI dashboard
- Provide business insights and recommendations

## 📂 Dataset Description

The dataset contains e-commerce transaction-level information including:

- Order information
- Customer information
- Product information
- Product categories
- Geographic information
- Payment methods
- Quantity
- Sales amount
- Discount
- Profit

### Important Columns

| Column | Description |
|---|---|
| `Order_ID` | Unique order identifier |
| `Order_Date` | Date on which the order was placed |
| `Customer_ID` | Unique customer identifier |
| `Product_Category` | Category of the product |
| `Product_Name` | Name of the product |
| `State` | State associated with the order |
| `City` | City associated with the order |
| `Payment_Mode` | Payment method used |
| `Quantity` | Quantity ordered |
| `Sales_Amount` | Sales/revenue generated |
| `Discount` | Discount applied |
| `Profit` | Profit generated |
